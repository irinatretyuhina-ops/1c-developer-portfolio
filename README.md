# Проекты

## ServiceCenter_1C

Информационная система автоматизации работы сервисного центра.

Проект моделирует реальные процессы обслуживания клиентов:
регистрация заявок, учет оборудования, выполнение работ сотрудниками,
расчет стоимости услуг и формирование аналитической отчетности.

---

# Реализованный функционал

### Управление клиентами и оборудованием

- ведение справочников клиентов;
- учет обслуживаемого оборудования;
- хранение информации о сотрудниках;
- классификация видов работ.

### Работа с заявками

Реализован полный цикл обработки заявки:

- создание заявки клиента;
- назначение ответственного сотрудника;
- установка приоритета и статуса;
- добавление выполняемых работ;
- контроль заполнения обязательных данных;
- проверка корректности проведения документа.

### Документы и бизнес-логика

Реализованы:

- документы с табличными частями;
- обработчики событий объектов;
- проверки данных перед записью и проведением;
- автоматическое заполнение реквизитов;
- формирование движений по регистрам.
