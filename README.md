# 🛠 Технические навыки

## Разработка на платформе 1С:Предприятие 8.3

- разработка прикладных решений с нуля;
- создание и настройка объектов метаданных;
- разработка справочников, документов, перечислений;
- проектирование реквизитов и табличных частей;
- разработка управляемых форм;
- программирование модулей объектов и форм;
- использование обработчиков событий;
- реализация пользовательской логики.

## Работа с данными

- написание запросов на языке 1С;
- работа с выборками данных;
- использование отборов и группировок;
- разработка отчетов на базе СКД;
- работа с регистрами сведений и накопления;
- формирование движений документов.

## Бизнес-логика

- проверка корректности пользовательских данных;
- контроль заполнения обязательных реквизитов;
- реализация сценариев проведения документов;
- автоматизация обработки данных;
- моделирование реальных бизнес-процессов.

## Администрирование и настройка

- создание подсистем;
- настройка командного интерфейса;
- работа с ролями и правами доступа;
- настройка пользовательских режимов работы.
