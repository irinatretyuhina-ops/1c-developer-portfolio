# ServiceCenter_1C

## Система автоматизации сервисного центра

Pet-проект на платформе **1С:Предприятие 8.3**, реализующий автоматизацию процессов учета заявок, оборудования, клиентов и выполненных работ сервисной организации.

Проект разработан с использованием управляемого приложения и ориентирован на моделирование реальных бизнес-процессов.

---

## Функциональные возможности

### Учет клиентов и оборудования

Реализованы справочники:

- Клиенты;
- Оборудование;
- Сотрудники;
- Виды работ;
- Должности;
- Подразделения.

Предусмотрено хранение информации о клиентах, обслуживаемом оборудовании и исполнителях работ.

---

### Работа с заявками на обслуживание

Реализован процесс обработки заявки:

- создание обращения клиента;
- указание оборудования;
- описание проблемы;
- изменение статусов заявки;
- передача заявки в работу.

---

### Выполнение работ

Документ **"Выполнение работ"** позволяет:

- фиксировать выполненные работы сотрудников;
- рассчитывать стоимость услуг;
- контролировать заполнение данных;
- формировать движения по регистру накопления.

Реализована программная логика проведения документа:

- проверки заполненности реквизитов;
- создание движений в регистре;
- автоматическое изменение статуса заявки.

---

## Учет данных

Используется регистр накопления:

**ВыполненныеРаботы**

Хранит информацию:

- сотрудник;
- клиент;
- вид работы;
- количество;
- сумма выполненных работ.

---

## Отчетность

Разработаны отчеты на базе **Системы компоновки данных (СКД):**

- Анализ выполненных работ сотрудников;
- Работа сотрудников.

Реализованы:

- группировки;
- отборы;
- параметры периода;
- вывод итоговых значений.

---

## Права доступа

Настроено разграничение доступа пользователей:

- Администратор системы;
- Мастер;
- Полные права.

Настроены роли и доступ к объектам конфигурации.

---

## Используемые технологии

- 1С:Предприятие 8.3
- Управляемые формы
- Конфигуратор 1С
- Язык запросов 1С
- СКД
- Регистры накопления
- Документы и проведение
- Роли и права доступа
- Git / GitHub

---

## Цель проекта

Практическая разработка конфигурации для закрепления навыков разработки на платформе 1С:Предприятие 8.3 и моделирования прикладных решений для бизнеса.
