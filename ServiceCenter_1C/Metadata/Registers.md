# Регистры


## Регистр сведений "ЦеныРабот"

Назначение:

Хранение стоимости выполняемых работ.


Используется для:

- автоматического заполнения цены;
- расчета стоимости работ.



## Регистр накопления "ВыполнениеРабот"

Назначение:

Учет выполненных сервисных работ.


Измерения:

- Сотрудник
- ВидРаботы
- Клиент


Ресурсы:

- Количество
- Сумма
